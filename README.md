# 小兔鲜电商首页

本项目是一个基于 HTML5 和 CSS3 开发的静态电商首页页面，用于练习常见网页布局和样式实现。

## 项目简介

小兔鲜是一个电商首页练习项目，包含导航栏、轮播图、商品展示、专题推荐和页脚等常见模块。项目主要用于巩固 HTML 页面结构搭建和 CSS 页面布局能力。

## 技术栈

- HTML5
- CSS3
- Flex 布局
- CSS 定位（position）
- 盒模型
- 伪类选择器
- 精灵图

## 实现功能

- 顶部快捷导航栏
- 主导航区域
- Banner 轮播展示区（静态）
- 商品分类展示
- 人气推荐模块
- 品牌专区
- 页脚区域

## 项目亮点

- 使用语义化 HTML 标签构建页面结构
- 使用 Flex 实现多种横向布局
- 熟练运用 margin、padding、position 完成页面排版
- 页面结构清晰，样式模块化
- 对电商首页布局有较完整的实践经验

## 项目收获

通过本项目，我掌握了：

- HTML5 页面结构搭建方法
- CSS 常见布局技巧
- Flex 布局使用方法
- 页面模块拆分思路
- 电商类首页的整体开发流程
